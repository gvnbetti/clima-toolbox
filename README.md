# Clima Toolbox (clima-toolbox)

Six browser tools for climate analysis and design guidance at the early stage of architectural projects.

| App | What it does | Folder | Published as |
| --- | --- | --- | --- |
| Clima Map | Finds a weather file: about 30,000 stations and 67,000 files on a map, nearest stations to any point, one-click download | `map/` | GitHub Pages only (map tiles) |
| Clima Morph | Writes the future climate and the urban heat island into a valid EPW file, for EnergyPlus, Ladybug and other tools | `morph/` | GitHub Pages only |
| Clima Compare | Two weather files side by side: two places, two periods of one place, or a place today against a warming level; every figure computed by Macro Clima's code, with a written reading of what carries over | `compare/` | GitHub Pages only |
| Macro Clima | Climate analysis of a weather file: comfort, solar, wind, future climate, urban heat island | `macro/` | Claude artifact (multi-file) |
| Micro Clima | Site and street-scale climate: outdoor comfort, shading, heat island, future climate | `micro/` | Claude artifact (single file) |
| Room Clima | Room and facade guidance: searches window size, glazing, shading, ventilation, mass and fans against daylight, comfort, energy and carbon targets; DIN 4108-2 summer check | `room/` | Claude artifact, v16 |

Live: https://gvnbetti.github.io/clima-toolbox/ (the apps run in the browser; nothing leaves it unless you use the optional AI assistant with your own API key).

(`LICENSE-docs.md`). To cite, see `CITATION.cff`.

## Layout

```
index.html    landing page, generated by shared/mklanding.py
map/          Clima Map (index.html, app.js, Leaflet 1.9.4 in vendor/); reads the station catalogue in macro/data/
morph/        Clima Morph (index.html, app.js, guide.js, epwout.js: writes the morphed EPW); loads macro/core.js (reader),
              macro/future.js, macro/regions.js and shared/climamods.js
compare/      Clima Compare (index.html, app.js, guide.js); loads Macro Clima's core.js, kit.js and sections.js, and
              shared/climamods.js, so every figure is Macro Clima's
macro/        Macro Clima source (index.html, app.js, core.js, sections.js, future.js, regions.js)
micro/        Micro Clima v8 (single built file)
room/         Room Clima v16
  src/          register.js (every constant with source and status), core.js (engine), shell.html, page.html,
                wxdata.line (bundled weather)
  build.py      assembles build/index.html and build/worker.js
  build/        built app as published
  edits/        scripted edits used to make each phase (history of changes)
  tests/        Node harness (h16.js) and checks; pw/ browser tests (Playwright, headless Chrome)
shared/       climamods.js: the calculation core shared by Macro, Micro and Room Clima (sun, Perez,
              psychrometrics, SolarCal, UTCI, future climate, urban heat island), generated from Macro Clima by
              mkmods.py; addcore.py puts it into Micro Clima's engine; wxrecord.py: turns an EPW file into a bundled
              weather record; addbar.py: the Clima Toolbox bar at the top of every app (rerun after
              editing it: map, macro, micro, and room/src/shell.html, then rebuild Room);
              mklanding.py: writes index.html, previews drawn from the repository's data;
              mkvalidation.py: writes validation.html from validation/README.md;
              mkmethods.py: writes methods.html and methods/*.html from docs/methods/*.md;
              bib.py: every reference, in APA style; mkrefs.py: writes the reference list of each method and
              validation page from the keys in its "<!-- refs: ... -->" line (run before mkmethods/mkvalidation);
              fonts/ (IBM Plex, OFL), icons/ (the six logos)
docs/         methods/: what each app computes, with its models, assumptions and sources
validation/   verification and validation of every model, by model: reports, scripts and results
              (thermal, daylight, climate reading, future climate, urban heat island, outdoor comfort, Clima Morph's file,
              Clima Compare)
```

## Build and test Room Clima

```
cd room
python3 build.py                      # writes build/index.html and build/worker.js
node tests/smoke.js                   # engine smoke test
node tests/modcheck.js                # shared modifiers against Macro Clima
python3 tests/pw/p2.py build          # browser run, Mannheim south office (needs Playwright and Chrome)
```

## Versions

One release number covers the whole toolbox: the six apps, the shared calculation core and the validation. It is in
`VERSION`, shown in the bar and in each app's header (written there by `shared/addbar.py`), in `CITATION.cff`, and
each release is a git tag (`v0.9.0`). 0.x releases are betas; 1.0.0 will be the first finished release. The minor
number goes up with new features, the last with fixes. The earlier histories (Room Clima v1 to v17, Micro Clima v1 to
v8) are kept in the apps' version notes.

## Validation

`validation/README.md` summarises every study: what is compared, against which reference, on which base cases, and
with what result. Each folder has its own report and the scripts to rerun it. The methods of the apps are described
in `docs/methods/`.

## Shared code

Macro, Micro and Room Clima compute sun position, sun on surfaces, psychrometrics, SolarCal, UTCI, future climate and the urban
heat island with the same code: `shared/climamods.js`, copied verbatim from Macro Clima. Clima Morph loads the same file
and writes its hourly values into the EPW it exports (`morph/epwout.js`). After changing any of these in
Macro Clima:
```
python3 shared/mkmods.py macro shared/climamods.js     # regenerate the core
python3 shared/addcore.py micro/index.html             # into Micro Clima's engine
cd room && python3 build.py                            # into Room Clima
```
Do not edit the generated file. The future-climate data (`macro/future.js`, `macro/regions.js`) are also read by
Micro and Room Clima from Macro Clima's folder.

## Bundled weather

Room Clima (`room/src/wxdata.line`) and Micro Clima (inside `micro/index.html`) carry six typical years:

| City | File | Source |
| --- | --- | --- |
| Mannheim | DEU_BW_Mannheim.107290_TMYx.2007-2021 | TMYx, climate.onebuilding.org |
| Bologna | ITA_Bologna TMYx 2004-2018 | TMYx, climate.onebuilding.org |
| Dubai | ARE_DU_Dubai.Intl.AP.411940_TMYx | TMYx, climate.onebuilding.org |
| Ho Chi Minh City | VNM_SVN_Ho.Chi.Minh-Tan.Son.Nhat.Intl.AP.489000_TMYx | TMYx, climate.onebuilding.org |
| San Francisco | USA_CA_San.Francisco.Intl.AP.724940_TMY3 | TMY3, NREL |
| Phoenix | USA_AZ_Phoenix-Sky.Harbor.Intl.AP.722780_TMY3 | TMY3, NREL |

TMYx: Lawrie, L. K., Crawley, D. B. Development of Global Typical Meteorological Years (TMYx).
https://climate.onebuilding.org. TMY3: Wilcox, S., Marion, W. (2008) Users Manual for TMY3 Data Sets,
NREL/TP-581-43156. Both are published free of charge; the data keep their sources' terms.

The DIN 4108-2 summer check is defined on the German test reference years (TRY) of the DWD. Mannheim here is TMYx,
so the bundled DIN result is indicative. For a formal check, load the TRY file for the site.
