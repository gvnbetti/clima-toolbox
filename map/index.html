Then

  1. Download the ZIP of the file you want.
  2. Open an app and drop the ZIP on its weather box. It reads the file inside.
  3. For other simulation tools, Clima Morph adapts the file to a future climate or an urban neighbourhood and returns it as an EPW.

The apps cannot fetch files from other servers, so the download goes through your computer. Nothing is uploaded.
